Privacy

Updated 9 September 2026

This page describes the website at divineconstruc.com. The Fate application is a separate thing and is covered at the bottom.

If you do not use the form, nothing is stored

There is no analytics on this site, no tracking pixel, no advertising tag and no cookie. Reading the page leaves nothing behind, and nothing about your visit reaches a database.

If you join the list, five things are stored

  • Your email address, lowercased and trimmed.
  • The date and time you submitted it.
  • Which of the coming paid features you ticked, if any. Ticking nothing is normal.
  • The message you wrote to me, if you wrote one. That step is optional.
  • A referral tag, only when the link you arrived on carried one as ?ref=. It is a plain label like a site name, not an identifier for you.

A random token is also generated so that the optional message can prove it belongs to your signup. It identifies the row, not you, and it is not used for anything else.

What is deliberately not stored

Your IP address and your browser user agent are not recorded, and no cookie is set. The endpoint that receives the form does not send mail, does not call any third party, and does not pass your address to anyone. It is not with a form vendor or a newsletter service. It sits in a database on an account I own.

Who else sees the request

One honest exception, because "nothing leaves" would be the easy sentence and not the true one. The typefaces are served from this domain, so loading this page fetches nothing from anywhere else.

  • Cloudflare hosts this site and runs the endpoint, so every request passes through their network and is subject to their own privacy terms. That is true of any hosted site and it is not something I can opt you out of.

What you will receive

One email, when one of the features you are waiting for is real. There is no newsletter and no drip sequence. If you wrote a message, I read it myself and I may write back.

Getting your address removed

Ask and it is deleted, with no conditions and nothing to confirm. Open an issue on the repository and say so, or reply to any email you get from me. Removal deletes the row, which takes the message and the ticks with it.

The application

Fate itself has no account, no telemetry and no analytics. It makes exactly one request on its own behalf: when it opens it asks GitHub whether a newer release exists, which is a plain request for a public file carrying no identifier and no version, and one click in the update panel stops it asking for good. Your notes are files on your own disk and nothing uploads them.

Changes

If what is stored changes, this page changes on the same day, and the date at the top is the honest one.
